# Escopo do projeto

## Dentro do escopo

A proposta do ClinAgenda abrange principalmente:

- organização de agendas;
- cadastro de pacientes;
- cadastro de unidades;
- cadastro de especialidades;
- cadastro de médicos;
- configuração de disponibilidade;
- agendamento;
- remarcação;
- cancelamento;
- prevenção de conflitos;
- lembretes;
- confirmação de presença;
- acompanhamento do status das consultas;
- histórico administrativo de atendimentos;
- indicadores básicos;
- controle de acesso;
- chatbot para interação com pacientes.

## Fora do escopo

Nesta proposta, não serão considerados:

- prontuário eletrônico;
- diagnósticos;
- receitas;
- exames;
- pagamento on-line;
- integração com convênios.

Esses itens podem ser avaliados futuramente, mas não são necessários para resolver o problema principal abordado pela atividade.

## Limite da atividade acadêmica

O projeto tem caráter de planejamento e documentação.

Não é necessário:

- programar o sistema;
- desenvolver um produto funcional;
- criar uma aplicação completa;
- implementar banco de dados;
- publicar o chatbot;
- colocar o sistema em produção.

O objetivo é apresentar uma solução coerente e demonstrar como diferentes áreas profissionais contribuiriam para seu planejamento e desenvolvimento.

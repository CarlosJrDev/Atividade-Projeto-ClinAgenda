# Protótipo demonstrativo do Front-end

Material complementar de **Ciro Junior**, para o ClinAgenda, produto da empresa fictícia **Tech Solutions**.

Baixe o repositório e abra [clinagenda.html](clinagenda.html) em um navegador. Não precisa instalar dependências nem conectar à internet. O GitHub exibe o código HTML; para interagir, abra o arquivo baixado localmente.

O cenário começa em 14/09/2026 e usa dados fictícios. A data é fixa para permitir repetir a apresentação. O menu **Restaurar demonstração** retorna ao cenário inicial, apagando as alterações locais da demo. Trabalhe em uma aba.

Agenda, pacientes, médico, gestão e conversas compartilham dados salvos no navegador. Não existe servidor conectado, autenticação real ou envio externo pelo WhatsApp. Copiar o HTML para outro computador não transfere alterações feitas no navegador.

Os slides internos trazem o nome Tech Solutions e o link do repositório; os dados do grupo podem ser editados na interface. Use o [roteiro de dois minutos](../docs/10-contribuicao-frontend-ciro.md) para a participação individual.

Não inserir dados reais de pacientes. A demonstração não comprova segurança, acessibilidade completa, desempenho clínico ou proteção contra acessos simultâneos de vários usuários.
